# Artifact Templates

This folder standardizes the outputs expected from the Opencluely planning agents.

Use these templates to improve:

- consistency across phases
- faster review and approval
- cleaner handoffs between agents
- easier consolidation into implementation tracks

## Rules

- Each agent should use one primary artifact template.
- Every agent should also produce a handoff packet using `00_HANDOFF_PACKET_TEMPLATE.md`.
- If a template section does not apply, mark it `N/A` instead of deleting it.
- Do not invent new artifact shapes unless the runbook explicitly requires them.
