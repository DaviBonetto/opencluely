# Legacy Audit Matrix

## Repository Snapshot

- Date audited: 2026-03-11
- Branch or workspace state: `git status --short` shows the repository as a fully untracked legacy snapshot. There is no `.gitignore`, runtime artifacts live in the root, and generated bytecode is present under `src/__pycache__`.
- High-risk areas:
  - `src/config.py` contains a live hardcoded Hugging Face token.
  - `config/lala_prep.json`, `config/notes.json`, and `config/templates.json` contain user/runtime data inside the repository.
  - Root `parakeet_*.log` files contain transcript fragments, AI output fragments, provider state, and local filesystem paths.
  - `src/ui/horizontal_overlay.py` and `src/ui/session_setup.py` are monoliths that mix UI, orchestration, persistence, and debug behavior.
  - `Imagens_Referência/` is uncategorized and does not follow the required `CURRENT_STATE` / `BAD_PATTERNS_TO_REMOVE` taxonomy.
