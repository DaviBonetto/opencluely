# Documentation

This folder contains the non-runtime material that still matters to the project.

## Structure

- `Codex_Orchestrator/`: archived planning packets, design handoffs, and phased implementation notes
- `reference-images/`: captured references used during the UI redesign process
- `legal/`: notices for bundled third-party assets
- `backend.md`: notes for the restored audio/Groq backend package layout
- `bugs.md`: preserved issue notes from earlier iterations

The application itself lives in the repository root and `src/`; this folder is intentionally for
documentation and reference material only.
